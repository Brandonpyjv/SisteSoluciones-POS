{# Macros compartidas para mostrar los errores de validación en los formularios. #} {# Resumen arriba del formulario. Sirve para los campos que no están a la vista porque quedaron en una pestaña o más abajo en la página. #} {% macro alerta(errores) -%} {% if errores %}
No se guardó: revisa los datos marcados
    {% for mensaje in errores.values() %}
  • {{ mensaje }}
    • {% endfor %}
{% endif %} {%- endmacro %} {# Clases del input con error. Los formularios usan `border-0`, que deja el borde en cero, así que hay que devolver también `border` para que el rojo se vea. #} {% macro invalido(errores, campo) -%} {{ ' is-invalid border' if errores and campo in errores else '' }} {%- endmacro %} {# Mensaje bajo el campo, uno solo para los dos casos. Si el servidor rechazó el dato, se muestra su mensaje con `d-block`, que lo deja visible pase lo que pase. Si no, el mismo hueco queda como contenedor del aviso del navegador, que Bootstrap revela cuando el formulario lleva `was-validated` y el campo no cumple. Así nunca se pintan dos mensajes. #} {% macro mensaje(errores, campo, ayuda='') -%} {% if errores and campo in errores %}
{{ errores[campo] }}
{%- else %}
{{ ayuda or 'Revisa este dato.' }}
{% endif %} {%- endmacro %}
